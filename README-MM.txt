မြန်မာ Recap Studio — စတင်အသုံးပြုရန်

ဒီ ZIP ထဲမှာ
- index.html: Website မျက်နှာပြင်
- netlify.toml: Netlify သတ်မှတ်ချက်
- netlify/functions/process.js: AI Server ချိတ်မည့်နေရာ
- package.json: Project အချက်အလက်

အရေးကြီး:
ဒီဗားရှင်းမှာ Website ပုံစံနဲ့ စာသားကူး/သိမ်း လုပ်ဆောင်ချက်တွေ ပါပါတယ်။
ဗီဒီယိုကို AI နဲ့ တကယ်ခွဲခြမ်းစိတ်ဖြာခြင်း၊ Recap ရေးခြင်း၊ မြန်မာအသံထုတ်ခြင်း မပါသေးပါ။
အဲဒီအတွက် backend AI/TTS provider ကို နောက်အဆင့်မှာ ချိတ်ဆက်ရပါမယ်။

Netlify တင်ရန်:
1. ZIP ကို ဖြည်ပါ။
2. GitHub repository အသစ်ဖန်တီးပါ။
3. ဖိုင်တွေကို repository ထဲ upload လုပ်ပါ။
4. Netlify မှာ Add new project > Import an existing project ကိုရွေးပြီး GitHub ချိတ်ပါ။
5. Publish directory ကို . ထားပါ။

API Key ကို HTML ဖိုင်ထဲ မထည့်ပါနှင့်။ Netlify Environment Variables ထဲမှာသာ သိမ်းပါ။
